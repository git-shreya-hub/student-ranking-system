Algorithm Explanation

What is Merge Sort?

Merge Sort is a Divide and Conquer algorithm. It works by recursively dividing the problem into smaller subproblems, solving them, and then combining the results.

Three Stages:

1. DIVIDE

Split the student records into two halves at mid = ⌊(low + high) / 2⌋. Continue splitting until each sublist has one element.

2. CONQUER

Recursively sort each half. A single element is already sorted by definition (base case).

3. COMBINE

Merge the sorted halves by comparing marks. The higher mark goes first (descending), and the complete record (roll, name, marks) moves together.

Pseudocode (backend/merge_sort.py)

MERGE_SORT(A, low, high)
    IF low < high
        mid = ⌊(low + high) / 2⌋
        MERGE_SORT(A, low, mid)          // Divide + Conquer
        MERGE_SORT(A, mid + 1, high)
        MERGE(A, low, mid, high)         // Combine
    END IF

MERGE(A, low, mid, high)
    left  = A[low..mid]
    right = A[mid+1..high]
    i = 0, j = 0, temp = []
    WHILE i < len(left) AND j < len(right)
        IF left[i] comes before right[j]
            temp.append(left[i]); i = i + 1
        ELSE
            temp.append(right[j]); j = j + 1
    END WHILE
    Append remaining left[i..], right[j..]
    Copy temp back into A[low..high]

"a comes before b" =
    a.marks > b.marks, or
    a.marks = b.marks AND a.roll ≤ b.roll

Complexity Analysis

CaseTime Complexity
Best CaseO(n log n)
Average CaseO(n log n)
Worst CaseO(n log n)
Auxiliary SpaceO(n)

Recurrence: T(n) = 2T(n/2) + O(n). By the Master Theorem (a = 2, b = 2, f(n) = n = nlog₂2) this is Θ(n log n).

There are log₂ n levels of recursion. Each level performs O(n) merge work. Therefore O(n) × O(log n) = O(n log n).

Competition Ranking with Ties

After sorting, ranks are assigned in one O(n) pass. If a student has the same marks as the previous student, they get the same rank; otherwise rank = position + 1.
